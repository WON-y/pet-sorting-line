# 배선

> 배선을 확정하면 사진과 함께 이 문서를 채운다. 핀 배치 초안: `safety/README.md`

## 전원 (safety_rules.md 3절)

```
12V 5A 어댑터(5.5×2.1, 센터 +) → DC 잭 단자(WS6) → 비상정지 HX19-B6(b접점, 직렬) → 릴레이(NO) → TB6600 VCC / GND
```

## 신호

```
게이트웨이 micro:bit P0 ─────────────────▶ 우노 D6 (모드 비트 0)
게이트웨이 micro:bit P1 ─────────────────▶ 우노 D7 (모드 비트 1)
게이트웨이 micro:bit P2 ─────────────────▶ 우노 D8 (하트비트)
micro:bit GND ◀──────────────────────────▶ 우노 GND
리셋 버튼 ───────────────────────────────▶ 우노 D10 ↔ GND
TB6600 PUL+ D3, DIR+ D4, ENA+ D5 (−는 GND), 전원 릴레이 IN D12
(선택) IR 도착 센서 OUT D2, IR 커튼 OUT D9, 비상정지 보조 접점 D11
```

전체 핀 표: `safety/README.md`. 우노 → micro:bit 방향 선은 없다 (5V가 micro:bit로 들어가지 않음).
