# PRD — 투명 페트병 선별 라인

> 이 파일은 팀 PRD 자리입니다. 기획서 v5 기준으로 요구사항·KPI ID만 먼저 옮겨 두었습니다.
> 팀이 PRD를 확정하면 이 내용을 바꿔 넣되, **ID(R·S·N)는 유지**해 주세요. 코드·커밋·이슈가 이 ID를 참조합니다.

## 1. 개요

- 문제: 기준에 안 맞는 병(라벨·내용물·유색)이 섞여 재생원료 품질이 떨어지고, 골라내는 사람은 도는 컨베이어 옆에서 끼임 위험을 안고 일하며, 작업 지시와 라인 상태가 소음 속에서 말과 눈짓으로만 오간다.
- 목표: 같은 기준의 자동 판정과 기록, 카드·손짓 지시와 손 모양 신호의 양방향 전달, 접근 시 저속·위험 시 반드시 정지.
- 범위 밖: 벨트 위에서 병 집어 올리기, 재질 구분, 미세 흠집, 학습하지 않은 병, 손동작 인식으로 정지, "사람보다 빠르다"는 주장, 안전 인증.
