# 안전 규칙

이 프로젝트에서 가장 중요한 문서입니다. **사람이 다치지 않게 하는 규칙**이므로, 다른 규칙과 충돌하면 이 문서가 이깁니다.

## 1. 절대 규칙

1. **정지는 전선과 센서로 한다.** 노트북, 도커, MQTT, YOLO, 손짓 인식은 정지 경로에 넣지 않는다.
2. **고장 나면 멈춘다(fail-safe).** 선이 빠지거나 신호가 끊기면 "정지"로 읽히도록 만든다.
3. **멈춘 뒤 저절로 다시 돌지 않는다.** 재가동은 카드·수신호 1 또는 2(모드 핀 `01`·`10`) + 리셋 버튼으로만. 노트북·대시보드는 실제 벨트를 재가동할 수 없다.
4. **비상정지 버튼은 12V 전원선에 직렬로 직접 연결한다(b접점).** 릴레이나 소프트웨어를 거치지 않는다.
5. **손짓·카드는 정지 수단이 아니다.** 사고는 신호를 보낼 겨를 없이 나기 때문이다. 저속·점검 잠금 같은 "일부러 내리는 지시"에만 쓴다.

## 2. 정지 경로 4개

| # | 감지 | 경로 | 노트북 필요? |
| --- | --- | --- | --- |
| ① | IR 커튼 (벨트 위 손) — **지금은 쓰지 않음** (펌웨어에 `USE_IR_CURTAIN` 선택으로만 남김) | IR 센서 → 우노 D9 → TB6600 ENA 끔 + 전원 릴레이 개방 | 아니오 |
| ② | 손 3 초음파 정지 거리 | 손 3 → 라디오 `mode`=3 → 게이트웨이 → 모드 핀 `00` → 우노 잠김 | 아니오 |
| ③ | 하트비트 끊김 | 손 3 신호 없음 또는 게이트웨이 빠짐 → P2 토글 멈춤 → 우노 잠김 (모드 선이 빠지면 `11` → 잠김) | 아니오 |
| ④ | 비상정지 버튼 | 12V 전원 직접 차단 | 아니오 |

## 3. 전원 연결 순서

```
12V 5A 어댑터 → 비상정지(b접점, 직렬) → 릴레이(NO, 우노가 정상일 때만 붙임) → TB6600 VCC
```

- 릴레이는 우노가 **정상이고 RUN 상태일 때만** 붙인다. 우노가 멈추거나 리셋되면 릴레이가 떨어져 전원이 끊긴다.
- 우노는 정지할 때 TB6600 `ENA`도 같이 끈다(이중).

## 4. 우노 펌웨어 규칙 (`safety/belt_controller`)

- 루프 안에서 `delay()`로 오래 멈추지 않는다. 스텝 펄스는 비차단 방식으로.
- 감지 → 정지까지 목표 0.5초 이하 (KPI N2).
- 정지 원인을 `EVT,STOP,<cause>`로 남긴다.
- 리셋 버튼은 모드 핀이 `01`(자동)·`10`(저속)이고 하트비트가 정상일 때만 잠김을 푼다. 그 밖의 리셋 입력은 거절하고 `RESET,REFUSED,<이유>`를 남긴다.
- 노트북 `PAUSE`/`GO`는 판정을 위한 **검사 멈춤**이며 안전 정지가 아니다. 잠김 상태에서 `GO`는 무시한다.
- 시리얼 시험 모드(`T`)는 micro:bit 없이 속도를 맞추는 용도다. 하트비트 검사를 건너뛰므로 사람이 옆에 있을 때만 쓰고, 이때도 재가동은 리셋 버튼으로만 한다.
- 전원을 켠 직후 상태는 **STOP**이다. 켜자마자 벨트가 돌면 안 된다.

## 5. 바꿀 때의 규칙

- `safety/` 폴더, `docs/spec/safety_rules.md`, 정지·하트비트 관련 메시지를 바꾸는 PR은 PR 템플릿의 **안전 체크리스트**를 모두 채운다.
- 바꾼 뒤에는 정지 시험(N1~N5)을 다시 하고 `docs/tests/kpi_log.md`에 기록한 다음 합친다.
- Claude 등 AI 도구로 이 영역을 고칠 때도 같은 규칙을 따른다. 사람이 시험하기 전에는 "완료"로 보고하지 않는다.

## 6. 시연 환경

- 바닥에 황흑 테이프: 정지 구역(약 20cm), 주의 구역(약 40cm).
- 작업자 수령 위치(부적합 슈트)는 접근 경고 감시 구역 밖에 둔다. 같으면 병을 받을 때마다 저속이 걸린다.
- 시연 전 점검: 비상정지 눌러 멈춤 확인 → 풀어도 안 도는지 확인 → 카드 1 + 리셋으로 재가동.
