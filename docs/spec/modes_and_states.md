# 운전 모드·상태·판정 규격

모드 번호, 우선순위, 판정 클래스는 모든 모듈이 같은 값을 써야 합니다.
파이썬 쪽 기준 값은 `common/protocol.py`, micro:bit·아두이노는 이 표를 보고 맞춥니다.

## 1. 운전 모드

| 번호 | 모드 | 벨트 | 4대 LED·소리 | 신호 손(3·4) | 작업 손(1·2) |
| --- | --- | --- | --- | --- | --- |
| 1 | 자동 | 보통 속도 | 초록 | 활짝 폄 | 판정대로 분기 |
| 2 | 저속 | 느리게 | 노랑 | 손가락 2개 | 판정대로 분기 |
| 4 | 점검 잠금 | 멈춤, 재가동 불가 | 빨강 깜빡임 | 주먹 + 손목 회전 | 날개판을 벨트와 나란히 접고 멈춤 |
| 5 (선택) | 도움 요청 | 그대로 | 손 4만 파랑 + 호출음 | 손 4 손가락 흔들기 | 그대로 |

- 3번은 쓰지 않는다(일시 정지는 비상정지 버튼과 겹침). 번호는 비워 둔다.
- 모드 입력: 숫자 카드(손 3 WonderCam) 또는 손짓(노트북 MediaPipe). 둘 다 **같은 번호**로 바꿔서 보낸다.
- 카드·손짓은 같은 값이 연속으로 보여야 확정한다(카드: WonderCam 예제 방식, 손짓: `gesture.confirm_frames`).

### 내려가기와 올라가기

- **멈추는 쪽은 바로**: 저속(2)·점검 잠금(4)은 확정 즉시 적용.
- **다시 켜는 쪽은 확인 뒤에**: 자동(1)으로 올라가려면 카드 1(또는 손짓 1) 확인 → 노트북이 우노에 `ARM` → 5초 안에 리셋 버튼.
- 점검 잠금(4) 중에는 1을 보여도 무시한다. 4를 치운(4가 안 보이는 상태 3초 이상) 뒤에만 1을 받는다.

## 2. 안전 단계 (danger level)

| 단계 | 감지 | 반응 | 풀리는 방법 |
| --- | --- | --- | --- |
| 0 정상 | | 모드대로 | |
| 1 접근 경고 | 손 3 초음파, 주의 거리 안 (`safety.warn_distance_cm`, 초안 40) | 저속, 4대 노랑, 느린 삐 | 사람이 떠나면 자동 복귀 |
| 2 위험 정지 | IR 커튼(우노 직결), 초음파 정지 거리(초안 20), P0 위험, 하트비트 끊김, 비상정지 | 벨트 즉시 정지, 4대 빨강, 연속음, 신호 손 주먹, 작업 손 그 자리 | 원인이 사라져도 안 켜짐 → 카드 1 + 리셋 버튼 |

- 오경보 필터(짧게 스친 감지 무시)는 **1단계에만**. 2단계는 한 번만 감지해도 멈춘다.

## 3. 우선순위

```
위험 정지(D2) > 점검 잠금(M4) > 접근 경고(D1) > 저속(M2) > 자동(M1)
```

높은 쪽이 걸려 있으면 낮은 쪽 명령은 무시한다. 모든 손과 app의 상태 계산은 이 순서를 따른다.

## 4. 판정 클래스

| 모델 클래스 (폴더 이름) | 판정 코드 | 분기 | 비고 |
| --- | --- | --- | --- |
| `clear_nolabel` | `OK` | 벨트 끝 투명 페트 통 | |
| `clear_label` | `NG` | 손 2 → 부적합 슈트 | |
| `clear_content` | `NG` | 손 2 → 부적합 슈트 | 데이터 확보 후 추가 |
| `color_nolabel` | `CO` | 손 1 → 기타 슈트 | |
| `color_label` | `CO` | 손 1 → 기타 슈트 | |
| (3프레임 불일치 또는 신뢰도 < `vision.conf_threshold`) | `RE` | 손 2 → 부적합 슈트 | 재검사 |

- 라벨과 내용물이 함께 있는 병은 `clear_label` 폴더에 넣고 manifest에 속성을 기록한다.
- 클래스를 추가하면 이 표, `common/protocol.py`의 `CLASS_TO_CODE`, 학습 manifest를 같이 고친다.

## 5. 병 한 개의 흐름 (app 상태 머신)

```
IDLE ─(EVT,ARRIVE)→ CAPTURE ─(3프레임)→ DECIDE ─(TX:J…)→ WAIT_ACK
  ↑                                                        │
  └──(GO 보냄, pet/sort 기록)── WAIT_SORT ←─(ACK 또는 OK면 바로)─┘
```

- `WAIT_ACK`: 손의 `ACK`를 `app.ack_timeout_ms`(기본 1500) 안에 못 받으면 1번 다시 보내고, 또 실패하면 `HOLD` + 대시보드 오류 기록.
- `OK`(적합)는 손이 움직이지 않으므로 바로 `GO`.
- 위험 정지나 점검 잠금이 걸리면 어느 상태에서든 `IDLE`로 돌아가고, 진행 중이던 병 id는 `aborted`로 기록한다. 재가동 뒤 그 병은 사람이 꺼내 다시 넣는다.

## 6. 작업 손(1·2) 상태

`RDY` → (자기 담당 판정 받음) → `OPEN`(날개판 30~45°) → (`sort_hold_ms` 뒤) → `DONE`(복귀) → `RDY`

- 위험 정지(`D2`): 날개판을 쥔 채 그 자리에서 멈춘다. **손가락을 펴지 않는다**(날개판이 떨어짐).
- 점검 잠금(`M4`) 또는 라디오 끊김(선택 S4): 날개판을 벨트와 나란히 접고 `SAFE`.
