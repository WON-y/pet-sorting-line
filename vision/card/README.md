# 비전: 숫자 카드 인식 (R6)

**실제 코드는 `hardware/hand3_signal`에 있다.** 카드 인식은 손 3의 WonderCam 내장 기능(공식 예제 6.10, 학습 불필요)으로 micro:bit 안에서 처리하기 때문이다. 이 폴더는 카드 규격과 시험 기록을 둔다.

## 카드 규격

| 카드 | 모드 | 비고 |
| --- | --- | --- |
| 1 | 자동 (재가동 확인) | 리셋 버튼과 함께 |
| 2 | 저속 | 즉시 적용 |
| 4 | 점검 잠금 | 즉시 적용, 잠금 중 1 무시 |
| 5 | 도움 요청 (선택 S1) | |
| 3 | 사용 안 함 | 비상정지 버튼과 역할이 겹쳐 비워 둠 |

## 지시대 환경

흰 배경 + LED 스트립 조명, 카드 거리 15~20cm, 높이는 실기로 정함.

## 시험 (KPI N7·N8)

카드 1·2·4 각 20회 인식, 카드를 보인 뒤 4대 표시·벨트 변화까지 2초 이하. 결과는 `docs/tests/kpi_log.md`.
