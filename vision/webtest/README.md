# 비전: 카메라 인식 웹 테스트 (R4 시험용)

휴대폰 카메라나 노트북 웹캠으로 찍은 사진을 노트북의 분류 모델로 인식하고, 결과를 웹 화면에 바로 띄우는 **시험 도구**입니다.

- 실행 위치: 노트북 (도커 아님, 모델·웹캠 때문)
- **라인을 제어하지 않고, MQTT로 판정을 보내지 않습니다.** 대시보드(`dashboard/`) 통계에 섞이지 않습니다.
- 안전 경로와 관계없습니다.

## 실행

```bash
pip install -r requirements-hw.txt -r dashboard/requirements.txt   # ultralytics + fastapi/uvicorn
python -m vision.webtest            # http://localhost:8100
python -m vision.webtest --https    # 휴대폰에서 실시간 카메라를 쓸 때
```

실행하면 터미널에 노트북 주소와 휴대폰 주소(같은 와이파이)가 나옵니다.

### 카메라 종류 (화면 왼쪽 위에서 선택)

| 선택 | 누가 카메라를 읽나 | 쓰는 경우 |
| --- | --- | --- |
| **노트북 USB 웹캠 (서버)** | 노트북 서버가 OpenCV로 직접 (`vision/bottle/camera.py`와 같은 방식) | 판정용 USB 웹캠. 브라우저 카메라 권한이 필요 없음. 노트북에서 열면 기본 |
| 이 기기 카메라 (브라우저) | 브라우저 (getUserMedia) | 휴대폰 카메라. 휴대폰에서 열면 기본 |

- 노트북 USB 웹캠은 "웹캠 0번/1번…" 중에서 고릅니다. 내장 카메라와 USB 웹캠 중 어느 쪽이 몇 번인지는 컴퓨터마다 다르니 화면을 보고 고르세요. 고른 번호는 브라우저가 기억하고, 기본값을 바꾸려면 `settings.yaml`의 `vision.camera_index`를 고칩니다.
- 웹캠은 한 프로그램만 쓸 수 있습니다. 줌·카메라 앱·다른 브라우저 탭이 쓰고 있으면 열리지 않습니다.
- 브라우저 모드에서 "브라우저가 카메라를 막았습니다"가 뜨면: 주소창 왼쪽 아이콘 → 사이트 설정 → 카메라 "허용" → 새로고침.

| 접속 방법 | 실시간 카메라 | 사진 찍어 올리기 |
| --- | --- | --- |
| 노트북 `http://localhost:8100` | 됨 (웹캠) | 됨 |
| 휴대폰 `http://<노트북IP>:8100` | 안 됨 (브라우저가 http에서 카메라를 막음) | 됨 |
| 휴대폰 `https://<노트북IP>:8100` (`--https`) | 됨 | 됨 |

- `--https`는 시험용 자체 서명 인증서를 `data/certs/`에 만듭니다(커밋 안 함). 휴대폰에서 "안전하지 않음" 경고가 뜨면 "고급 → 계속"을 누르세요.
- 휴대폰이 접속되지 않으면 윈도우 방화벽에서 파이썬의 개인 네트워크 접근을 허용하세요. 학교·공용 와이파이는 기기끼리 막혀 있을 수 있습니다(휴대폰 핫스팟에 노트북을 붙이면 됩니다).

## 모델

| 상황 | 쓰는 모델 | 화면 |
| --- | --- | --- |
| `training/weights/best.pt` 있음 (`vision.weights`) | 학습한 4클래스 모델 | 판정 코드 OK/NG/CO/RE + 상위 클래스 |
| 없음 (지금) | `webtest.fallback_model` (ImageNet 기본 분류, 처음 한 번 자동 다운로드) | 상위 5개 클래스와 신뢰도만 (판정 코드 없음) |

- 4클래스 모델일 때는 `vision/bottle`과 **같은 전처리**(`prepare`: 판정 구역 자르기 + 224 회색 레터박스)와 **같은 판정 규칙**(`decide`, 1프레임, `vision.conf_threshold` 미만이면 RE)을 씁니다.
- 다른 가중치를 시험하려면 `python -m vision.webtest --model 경로/모델.pt` (분류 모델만).
- `vision.roi`가 정해져 있으면 "판정 구역만" 선택이 나타나고, 노란 점선 상자로 표시합니다. 좌표는 1280×720 웹캠 사진 기준이라 휴대폰 사진에는 끄고 쓰세요.

## 화면 기능

- 카메라 종류 선택(노트북 USB 웹캠 / 이 기기 카메라), 웹캠 번호 선택, 켜기/끄기 (휴대폰은 기본 후면 카메라)
- 한 장 인식 / 자동 인식 (`webtest.interval_ms` 간격)
- 사진 찍어 올리기 (갤러리 사진도 가능)
- 결과: 판정 코드(또는 1위 클래스) 큰 표시, 상위 5개 막대, 처리 시간, 최근 12장 기록

## 파일

| 파일 | 내용 |
| --- | --- |
| `__main__.py` | 실행, 접속 주소 출력, `--https` 인증서 생성 |
| `server.py` | FastAPI: `GET /`, `GET /api/info`, `GET /api/server_camera/frame.jpg?index=`, `POST /api/predict?roi=0|1` (본문: JPEG/PNG 바이트) |
| `server_camera.py` | 노트북 USB 웹캠을 OpenCV로 읽기 (한 번에 하나, 번호 바꾸면 이전 것 닫음) |
| `recognizer.py` | 모델 열기(학습 가중치 → 없으면 기본 모델), 전처리·상위 클래스·판정 코드 |
| `static/index.html` | 화면 (빌드 도구·외부 CDN 없음) |

시험: `tests/test_webtest.py` (가짜 모델로, ultralytics 없이)

## 주의

- 이 도구의 HTTP 경로는 시험용이라 `docs/spec/protocol.md` 6절(대시보드 API)에 넣지 않았습니다. 대시보드 컨테이너에 합치려면 먼저 규격 변경을 제안하세요.
- 휴대폰 사진은 실제 벨트 위 사진과 조명·각도가 다릅니다. 정확도(KPI N10·N11) 평가는 벨트 사진으로만 합니다.
