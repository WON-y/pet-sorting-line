# 손 3 — 지시대 신호 손

- 실행 위치: 손 3 micro:bit + WonderCam + 초음파 (MakeCode)
- 담당: R1(접근 경고), R2(위험 정지 신호), R6(카드 → 모드, 복창), 하트비트

## 하는 일

| 입력 | 처리 | 출력 |
| --- | --- | --- |
| WonderCam 숫자 카드 1·2·4(5) | 같은 번호 연속 인식 시 확정 (점검 잠금 중 1 무시) | 라디오 `M1`/`M2`/`M4`, 손가락 복창 |
| 초음파 거리 < `warn_distance_cm`(40) | 짧은 오경보 필터 후 | `D1`, 노랑, 느린 삐 |
| 초음파 거리 < `stop_distance_cm`(20) | 필터 없이 즉시 | `D2`, 빨강, 주먹 |
| 거리 회복 | 경고만 자동 해제 | `D0` (위험 정지는 해제하지 않음) |
| 타이머 200ms | | `HB3,<seq>` 하트비트 |

## 손 모양 (`modes_and_states.md` 1절)

활짝 = 자동, 손가락 2개 = 저속, 주먹 = 정지, 주먹 + 손목 회전 = 점검 잠금

## 안전 주의

- 하트비트는 다른 처리(카드 인식 등) 때문에 늦어지지 않게 별도 반복(`forever` / `every 200ms`)에 둔다.
- 카드 인식은 정지 수단이 아니다. 정지는 초음파 → `D2`로만.
- 숫자 카드 인식 설명: `vision/card/README.md`
