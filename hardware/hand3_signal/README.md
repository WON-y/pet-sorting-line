# 손 3 — 지시대 신호 손

- 프로그램: `code/microbit/hand3_signal.ts` (WonderCam + 초음파)
- 담당: R1(접근 경고), R2(위험 정지 신호), R6(수신호·카드 → 모드, 복창). **이 손이 모드의 기준이다.**

## 하는 일

| 입력 | 처리 | 출력 |
| --- | --- | --- |
| WonderCam 수신호 (ID 1 OK 사인, 2 V, 3 주먹, 4 손바닥 활짝) | 올라가기(→1·2)는 3초 유지 + 3초 예고, 내려가기·정지는 약 0.5초, 잠금은 약 1초 | 모드 변경, 손가락 복창 |
| 숫자 카드 (로고 길게 눌러 전환) | 수신호와 같은 번호. 카드 5 = 도움 요청 | |
| 초음파 < `WARN_MM`(400mm) | 연속 3번이면 인정 (오경보 필터) | `dng` = 1, 경고음 |
| 초음파 < `STOP_MM`(200mm) | 필터 없이 즉시 | `dng` = 2, **모드 3(정지)으로 바꿈** |
| 점검 잠금(4) 중 | 수신호·카드로 못 바꿈 (A+B로 해제) | |
| 0.3초마다 | 살아 있음 신호를 겸해 다시 보냄 | 라디오 `mode`, `help`, `dng` |

## 안전 주의

- 이 손의 `mode` 신호가 끊기면 게이트웨이가 1.5초 뒤 모드 핀 `00` + 하트비트를 멈춰 우노가 잠긴다.
- 수신호·카드 인식은 정지 수단이 아니다. 정지는 초음파 → 모드 3으로 한다.
- 접근 경고(`dng` = 1)는 벨트 속도를 바꾸지 않는다 (손짓·소리, 출발 금지만). 팀 결정 → `docs/spec/modes_and_states.md` 2절
