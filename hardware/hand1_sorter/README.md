# 손 1 — 작업 손 (유색·불투명 분기)

- 담당 판정 코드: `CO` (`docs/spec/protocol.md` 1절)
- 실행 위치: 손 1 micro:bit (MakeCode)

## 상태와 동작 (`docs/spec/modes_and_states.md` 6절)

| 상태 | 조건 | 동작 | 보내는 메시지 |
| --- | --- | --- | --- |
| `RDY` | 시작, 복귀 완료 | 날개판을 벨트와 나란히(대기) | `H1,RDY` |
| `OPEN` | `J<id>,CO` 받음 | `ACK1,<id>` 보내고 손목을 돌려 날개판 30~45° | `ACK1,<id>`, `H1,OPEN` |
| `DONE` | `sort_hold_ms`(1200) 지남 | 날개판 복귀 | `H1,DONE` → `RDY` |
| 정지 | `D2` 받음 | **그 자리 멈춤, 손가락 펴지 않음** | |
| `SAFE` | `M4` 받음 (선택 S4: 라디오 끊김) | 날개판 접고 멈춤 | `H1,SAFE` |

## 확인할 것

- [ ] 손목 회전축이 세로축인지(날개판이 벨트 위에서 수평으로 도는지)
- [ ] 30°/45° 중 병이 쓰러지지 않는 각도 (KPI N12)
- [ ] 날개판 헛돎·떨어뜨림 50회 중 0회 (N13)
