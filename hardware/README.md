# 하드웨어 제어 (AIHand 손 1~4)

AIHand마다 micro:bit 하나가 들어 있고, MakeCode로 만든 프로그램이 손가락·손목 서보와 센서를 움직인다.

| 폴더 | 손 | 역할 | 담당 요구사항 |
| --- | --- | --- | --- |
| `hand1_sorter` | 손 1 (작업 손) | 날개판으로 유색·불투명(`CO`) 병을 기타 슈트로 | R5 |
| `hand2_sorter` | 손 2 (작업 손) | 날개판으로 부적합(`NG`)·재검사(`RE`) 병을 부적합 슈트로 | R5 |
| `hand3_signal` | 손 3 (지시대 신호 손) | 숫자 카드 인식, 손가락 복창, 초음파 접근 감지, 하트비트 | R1, R2, R6 |
| `hand4_remote` | 손 4 (원격 신호 손) | 떨어진 자리에서 모드·위험을 손가락·LED로 표시 | R6, R7 |

## 공통 규칙

- 실행 위치: 각 손의 micro:bit. 언어: MakeCode(블록 또는 TypeScript).
- 메시지는 `docs/spec/protocol.md` 1절, 모드·우선순위는 `docs/spec/modes_and_states.md`를 따른다.
- 폴더마다 남길 것: `README.md`(상태·동작 표), MakeCode **공유 링크** 또는 프로젝트 파일(`main.ts`, `pxt.json`), 최신 `.hex`.
- 프로그램 맨 위에 상수(라디오 그룹, 거리, 시간)를 모으고, 옆에 `settings.yaml` 키를 주석으로 적는다.
- 받은 메시지는 LED에 잠깐 표시, 모르는 메시지는 무시.
- 서보를 쓰는 micro:bit는 USB 시리얼을 쓸 수 없다. 디버깅은 LED·소리로 한다.
- 대여품: 펌웨어 교체·분해 금지. 날개판은 벨크로·고무줄로 고정(원상복구 가능).
