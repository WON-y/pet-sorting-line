# 손 4 — 원격 신호 손

- 실행 위치: 손 4 micro:bit (MakeCode), 관리자 자리에 둠
- 담당: R6(복창), R7(4대 동시 표시), S1(도움 요청 표시)

| 받은 메시지 | 손 모양 | LED·소리 |
| --- | --- | --- |
| `M1` | 활짝 | 초록 |
| `M2` | 손가락 2개 | 노랑 |
| `M4` | 주먹 + 손목 회전 | 빨강 깜빡임 |
| `M5` (선택) | 손가락 흔들기 | 파랑 + 호출음 |
| `D1` | (모드 유지) | 노랑 + 짧은 경고음 |
| `D2` | 주먹 | 빨강 + 연속음 |
| `D0` | 현재 모드 모양 | 모드 색 |

우선순위(`modes_and_states.md` 3절)에 따라 가장 높은 상태를 표시한다.
