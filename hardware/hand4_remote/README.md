# 손 4 — 원격 신호 손

- 프로그램: `code/microbit/hand4_display.ts`
- 실행 위치: 관리자 자리에 둠. 센서 입력 없음
- 담당: R6(복창), R7(4대 동시 표시), S1(도움 요청 표시)

표시 우선순위: 도움 요청 > 접근 위험 1 > 평소(모드 자세). 위 칸이 걸려 있으면 그것만 보여 준다.

| 받은 라디오 | 손 모양 | LED·소리·화면 |
| --- | --- | --- |
| `help` 1 | 손가락 하나씩 흔들기 | 파랑, 2초마다 호출음, 화면 `H` |
| `dng` 1 | "멈춰" 손짓 | 경고음, 화면 `!` |
| `dng` 2 | | 긴 경고음, 화면 `X` |
| `mode` 1 | OK 사인 | 초록 |
| `mode` 2 | 손가락 2개 (V) | 노랑 |
| `mode` 3 | 주먹 | 빨강 |
| `mode` 4 | 활짝 + 손목 회전 | 빨강 깜빡임 |
| `mode`가 2초 동안 안 옴 | 주먹 | 보라, 화면 `?`, 낮은 경고음 |

정확한 동작은 `code/README.md` 6.3절.
