# 손 2 — 작업 손 (부적합·재검사 분기)

- 프로그램: `code/microbit/hand12_sorter.ts`에서 `HAND_ID = 2`
- 담당 판정: 판정 번호 0 = `RE`, 3 = `NG` (2 = 내용물 남음도 분기하지만 지금 모델은 보내지 않음) (`docs/spec/protocol.md` 1절)

## 동작 (`docs/spec/modes_and_states.md` 6절)

| 받은 것 | 동작 |
| --- | --- |
| 라디오 `jdg`, 판정 0·2·3 | 손목을 돌려 날개판을 벨트 위로 비스듬히 (분기) |
| 라디오 `jdg`, 그 밖의 판정 | 날개판을 벨트와 나란히 (통과) |
| `mode` 3 (일시 정지) | 그 자리 멈춤. 받은 판정은 기억했다가 1·2가 되면 적용 |
| `mode` 4 (점검 잠금) | 날개판을 나란히 접고 멈춤, 기억한 판정 버림 |
| `mode`가 2초 동안 안 옴 | 그 자리 멈춤, 보라색 LED |

- 손은 응답 메시지(ACK·상태)를 보내지 않는다. 노트북은 게이트웨이의 `ACK,순번,판정`으로 "보냈음"만 확인한다.
- 날개판은 다음 판정을 받을 때까지 그 각도를 유지한다.

## 확인할 것

- [ ] 손목 회전축이 세로축인지(날개판이 벨트 위에서 수평으로 도는지)
- [ ] 30°/45° 중 병이 쓰러지지 않는 각도 (KPI N12) → `WRIST_DIVERT`
- [ ] 날개판 헛돎·떨어뜨림 50회 중 0회 (N13)
