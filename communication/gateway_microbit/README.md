# 게이트웨이 micro:bit

- 실행 위치: 확장보드 없는 micro:bit 1개 (USB 시리얼 사용), 노트북 USB에 꽂음
- **프로그램: `code/microbit/gateway_bridge.ts`** (제어 담당 코드가 기준. 이 폴더에는 설명만 둔다)
- 악어클립 듀폰선으로 우노와 연결 (P0·P1·P2·GND)

## 하는 일 (`docs/spec/protocol.md` 1~3절)

| 입력 | 동작 |
| --- | --- |
| 라디오 `mode` = 1~4 (손 3이 0.3초마다) | 모드 핀 (P1,P0) 출력: 자동 `01`, 저속 `10`, 일시 정지 `00`, 점검 잠금 `11`. 바뀌면 시리얼 `MODE,n` |
| 라디오 `mode`가 오는 동안 | P2 하트비트 0.1초마다 토글 |
| 라디오 `mode`가 1.5초 동안 안 옴 | 모드 핀 `00`(정지) + 하트비트 멈춤, 시리얼 `LINK,LOST` |
| 라디오 `dng` = 0·1·2 | 시리얼 `DNG,n` (핀은 바꾸지 않음. 정지는 손 3이 모드 3을 보내서 함) |
| 라디오 `help` = 0·1 | 시리얼 `HELP,n` |
| 시리얼 `J0`~`J4` (노트북 판정) | 라디오 `jdg` = 순번×10 + 판정 번호, 3번 반복. 시리얼 `ACK,순번,판정` |
| 켜질 때 | 모드 핀 `00`(정지), 화면 `?` |

## 주의

- 우노 → micro:bit 방향 선은 없다 (5V가 micro:bit로 들어가지 않게).
- 서보 확장을 쓰지 않는다 (쓰면 USB 시리얼이 안 됨).
- 라디오 그룹은 손 4대와 같아야 한다 (`RADIO_GROUP = 73`, `settings.yaml`의 `radio.group`).
