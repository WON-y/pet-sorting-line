# 게이트웨이 micro:bit

- 실행 위치: 서보가 없는 micro:bit 1개 (USB 시리얼 사용 가능), 노트북 USB에 꽂음
- 악어클립 듀폰선으로 우노와 연결 (P0·P1·P2·GND)

## 하는 일 (`docs/spec/protocol.md` 1~3절)

| 입력 | 동작 |
| --- | --- |
| 라디오 수신 | 시리얼로 `RX:<메시지>` |
| 시리얼 `TX:<메시지>` | 라디오로 그대로 전송 |
| 라디오 `D2` | **즉시 P0 HIGH** (노트북 거치지 않음) |
| 라디오 `D0` | P0 LOW |
| 라디오 `HB3,<seq>` | P1 HIGH/LOW 바꾸기 |
| 핀 P2 HIGH (우노 정지) | 라디오 `D2`, 시리얼 `PIN:STOP` |
| 핀 P2 LOW | 시리얼 `PIN:RUN` |
| 켜질 때 | P0 HIGH(정지 쪽)로 시작, 시리얼 `GW:BOOT` |

## 주의

- P2에는 반드시 분압(1kΩ·2kΩ)을 거친 3.3V만 들어와야 한다. 5V 직결 금지.
- 서보 확장을 쓰지 않는다(쓰면 USB 시리얼이 안 됨).
